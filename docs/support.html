Help for Selective Content Hider.

Install from source

  1. Open chrome://extensions
  2. Turn on Developer mode
  3. Load unpacked and select the extension folder

Common questions

A hide stopped working after the site redesigned. Start hiding again and click the section. Old selectors can break when a page’s markup changes.

I need the hidden UI for a minute. Use Pause this site. Rules stay; the page shows in full until you unpause.

How do I back up my rules? Open All sites in the popup, then Export.
