Chrome extension

Hide the parts of a page you don’t need.

Click a section to remove it. The choice stays on that website until you restore it. Nothing is sent to a server we operate.

View on GitHub Privacy policy

How it works

  1. Open the extension and press Start hiding.
  2. Click any section on the page.
  3. Restore it from the bar on the page, the popup, or the All sites page.
